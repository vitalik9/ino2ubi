# Сверка исходного .ino с полученным .ubi

Дата: 2026-11-02. База: ino2ubi 2.16 Runtime Safety.

## Реализация

Введён самостоятельный модуль `roundtrip.js`. Он считывает окончательно сформированный SIXX XML через XML DOMParser и сравнивает сохранённые разделы с представленными в исходном `.ino` конструкциями и настройками ролей. Расхождения блокируют скачивание; пользователь получает отчёт со списком элементов.

## Покрытие

- Code Basic: setup/loop (с учётом трансформаций параметров и En), функции (тело/тип/аргументы), типы и имена контактов, параметры/значения, includes и их порядок, defines, глобальные объявления, BLE callback и его внутренние переменные.
- Code Professional: setup/loop восстанавливаются из FLProg редакторских текстов и ссылочных тегов; проверяются ключевые объявления и пользовательские функции. Полная проверка логики всех узлов графа шаблона не реализована.
- RemoteXY: только прежняя структурная проверка XML; без сверки с исходным скетчем.

## Проверки

- браузер: простой скетч Code Basic, BLE Presence Code Basic, простой Code Professional — экспорт выполнен, ошибок сверки нет;
- негативные сценарии: повреждение loop, удаление функции, изменение параметра 60000UL, замена типа входа, удаление #include — расхождения обнаружены;
- исходные тесты: BLE 11, преобразование 35, числовые литералы 30, риски выполнения 19 — пройдены;
- реальные тесты в FLProg и на ESP32 для **этой** сборки не выполнялись.

## Границы достоверности

Проверка не доказывает семантическую эквивалентность программ и не обнаруживает все ошибки парсера, если тот проигнорировал неизвестную конструкцию. Нужны отдельная сверка с итоговым сгенерированным FLProg C++, компиляция и испытания на устройстве.
