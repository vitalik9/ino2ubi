# Подписи и описания параметров Code Professional

Изменены `parser.js` и `professional.js`.

- русские подписи в `// par:` теперь сохраняются как название параметра;
- ` | description: Текст` сохраняется в `description` параметра `.ubi`;
- `choices:` можно комбинировать с `description:` в любом порядке;
- старый синтаксис `// par: Подпись` продолжает работать.

Для проверки парсера: `node tests/parameter-descriptions-regression.js`.
Проверка импорта в FLProg 9.8.x и полного браузерного экспорта `.ubi` в текущем окружении не проводилась.
