Code Professional — инструкция

Конвертер создаёт один .ubi в формате Code Professional для FLProg.

Вставьте или откройте .ino, нажмите «Парсить код», проверьте входы, выходы и параметры, затем «Сгенерировать Code Professional .ubi».

Маркеры: // in — вход; // out — выход; // par: Описание — параметр; // variable — внутренняя переменная.

Для сохранения правок используйте «Сохранить проект» (.i2u.json). Старые проекты Basic можно открывать, но экспорт всегда создаётся в Professional.

RemoteXY пока не поддерживается в формате Professional. Проверка в браузере не заменяет импорт и компиляцию в FLProg.

Целевая среда: FLProg 9.8.6 / ESP32 Arduino Core 3.3.11. Диагностика не заменяет компиляцию в FLProg.
